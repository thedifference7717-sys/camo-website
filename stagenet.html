Join the stagenet

The stagenet is a full rehearsal of CAMO before mainnet: same rules, same privacy, coins with no value. Run a node, mine, send private payments, try to break things, and report what you find.

NETWORK
stagenet

add --stagenet to every command

P2P PORT
39740

open it to help the network

NODE RPC
39741

local only by default

ADDRESSES START
Q

mainnet addresses start with C

BEFORE YOU START

  • Stagenet coins are worthless and the chain may be reset. Never buy or sell them.
  • Never reuse a stagenet wallet's 25 words for real money. Make a fresh wallet for mainnet.
  • Signed downloads arrive Dec 7. Until then you build from source (about 45 minutes, steps below).

01 Build CAMO

On Linux (Ubuntu 22.04 or 24.04), install the build tools, then build the node and wallet:

sudo apt update
sudo apt install -y git build-essential cmake pkg-config libssl-dev libzmq3-dev \
  libunbound-dev libsodium-dev libunwind8-dev liblzma-dev libreadline-dev \
  libexpat1-dev libpgm-dev libhidapi-dev libusb-1.0-0-dev libprotobuf-dev \
  protobuf-compiler libudev-dev libboost-all-dev

git clone --recurse-submodules https://github.com/thedifference7717-sys/camo
cd camo && mkdir -p build/release && cd build/release
cmake -DARCH=x86-64 -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTS=OFF -DUSE_DEVICE_TREZOR=OFF ../..
make -j$(nproc) daemon simplewallet
cd bin

On a Mac with Homebrew: brew install cmake pkg-config boost openssl zeromq unbound libsodium expat readline hidapi protobuf libusb, then the same git clone, cmake and make (use -DARCH=armv8-a on Apple Silicon). If Homebrew's newest Boost breaks the build, use Linux.

02 Start a node

Until the seed nodes are built into the software, point your node at them by hand:

./camod --stagenet \
  --add-priority-node 34.171.218.2:39740 \
  --add-priority-node 3.134.132.214:39740

Leave it running. It syncs the chain into ~/.camo/stagenet. Type status in its window to see the height and peers, and exit to stop it cleanly.

03 Make a test wallet

In a second terminal, in the same bin folder:

./camo-wallet-cli --stagenet --generate-new-wallet stagenet-test

Pick a password, then write the 25 words on paper. Your address starts with Q. Type address to show it again.

04 Mine test coins

In the wallet, start mining to yourself with two CPU threads:

start_mining 2

Or mine with XMRig, the way you will on mainnet: see the mining guide and use port 39741 for solo mining against your stagenet node. Mined coins unlock after 60 blocks (about an hour). Type stop_mining to stop.

05 Send a private payment

Swap addresses with another tester (or make a second wallet), then:

transfer Q…their address… 5

Every payment uses a ring of 16 and hides the amount. Check what the chain reveals in the stagenet block explorer: [STAGENET EXPLORER LINK].

06 Help the network

  • Open TCP port 39740 on your router or firewall so other nodes can reach yours.
  • Restore a wallet from its 25 words (--restore-deterministic-wallet) and check the balance comes back.
  • Stop your node for a while, restart it and watch it catch up.
  • Report bugs on GitHub issues. Report security problems privately to camocoin@proton.me, never in public.
